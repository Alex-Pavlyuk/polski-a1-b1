# Polski A1–B1 — інтерактивний курс польської

*Interaktywny kurs języka polskiego od poziomu A1 do poziomu B1.*

**Автор:** Alex Pavlyuk · [github.com/Alex-Pavlyuk](https://github.com/Alex-Pavlyuk)

**▶ Спробувати курс:** https://alex-pavlyuk.github.io/polski-a1-b1/

Курс для україномовних учнів, які вже мають базу A1: 12 тижнів × 5 уроків (кожен ≤ 30 хвилин),
контрольний тест A2 після 6-го тижня і підсумковий іспит B1.

У кожному уроці шість кроків: **слова** (картки з озвученням) → **граматика** (пояснення українською,
клікабельні польські приклади, запитання викладачеві-Claude) → **вправи** (вибір, пропуски, порядок
слів, зіставлення, переклад; «ще 5 вправ» від Claude) → **вимова** (послухай і повтори, мінімальні
пари, наголос, диктант) → **читання або аудіювання** (текст можна спершу тільки слухати) →
**письмо** (твір з живим чек-листом, перевіркою Claude і зразком).
Оцінка уроку — за польською шкільною шкалою 1–6.

Крім уроків, щотижня:
- **Rozmowa** — рольовий діалог із Claude на тему модуля (лікар, співбесіда, вокзал…) з виправленням помилок і підсумковою оцінкою;
- **Zadanie z życia** — справжній польський документ (оголошення, меню, розклад, ulotka, вакансія) із запитаннями та короткою відповіддю.

Інструменти:
- **картки** — інтервальне повторення слів пройдених уроків (1, 3, 7, 16, 35 днів);
- **зошит помилок** — кожне завдання з помилкою потрапляє туди; робота над помилками і схожі завдання від Claude;
- **мапа прогресу** — результати всіх уроків і список тем, які варто повторити;
- **нагадування** — щоденна подія в Google Календарі (локально — файл .ics).

| Тижні | Рівень | Теми |
|---|---|---|
| 1–6 | A2 | теперішній час і знахідний, минулий і орудний, родовий і числівники, вид дієслова і майбутній час, місцевий і дієслова руху, давальний і наказовий спосіб |
| 6 | A2 | контрольний тест A2 |
| 7–12 | B1 | чоловічо-особовий рід і множина, умовний спосіб і żeby, ступені порівняння, префіксальні дієслова руху і час, który і непряма мова, дієприкметники, пасив і безособові форми |
| 13 | B1 | підсумковий іспит: граматика, лексика, читання, аудіювання, письмо (поріг 60%) |

**Додаткові модулі** (необов’язкові, можна проходити будь-коли; не входять у прогрес курсу й обсяг іспитів):
- **Dodatek 1 · Przypadki w praktyce** — система відмінків, родовий vs знахідний, орудний vs місцевий, давальний, кличний і займенники;
- **Dodatek 2 · Czasy w praktyce** — теперішній, минулий і майбутній час, вид дієслова в усіх часах;
- **Dodatek 3 · Liczebniki** — числа до 100 з акцентом на десятки (40, 50, 60…), сотні й тисячі, узгодження з іменниками, відмінки числівників, порядкові й десятиліття.

## Швидкий старт

Потрібен лише [Node.js](https://nodejs.org/) 18+; сторонніх залежностей немає.

```bash
node tools/validate.js   # перевірити весь контент
node tools/build.js      # зібрати dist/polski-a1-b1.html
```

Після збирання відкрийте `dist/polski-a1-b1.html` у браузері — це один самодостатній файл,
його можна викласти на будь-який статичний хостинг (GitHub Pages, Netlify) або просто переслати.

Технічно це односторінковий застосунок на чистому JavaScript без фреймворків: рушій у `src/`,
увесь навчальний контент — у `course/` як дані, тож урок можна змінити, не чіпаючи коду.

## Як навчатися

- **Онлайн на GitHub Pages:** https://alex-pavlyuk.github.io/polski-a1-b1/ — сайт автоматично
  перезбирається з гілки `main` (`.github/workflows/pages.yml`). Прогрес зберігається в браузері,
  працює розпізнавання мовлення, а твори перевіряють LanguageTool і AI-екзаменатор (див. нижче).
- **Онлайн на Netlify:** https://polski-kurs.netlify.app — та сама збірка, що й на GitHub Pages
  (налаштування в `netlify.toml`), з тими самими перевірками творів.
- **Онлайн на claude.ai:** у цій версії працюють перевірка творів і перекладів,
  діалоги та додаткові вправи від Claude, а прогрес синхронізується між пристроями.
- **Локально або на власному хостингу:** зберіть курс (див. вище) і відкрийте `dist/polski-a1-b1.html`
  у Chrome, Edge або Safari. Прогрес зберігається в браузері, працює розпізнавання мовлення
  (кнопка «Вимовити»), але функції Claude там вимкнені — вони потребують середовища claude.ai.
- Для озвучення потрібен польський голос: на macOS — Системні параметри → Доступність →
  Озвучений вміст → Голоси → Polski (Zosia); у Chrome польський голос Google є за замовчуванням.

## Перевірка творів на GitHub Pages і Netlify

- **Граматика — [LanguageTool](https://languagetool.org/)**: безкоштовний публічний API, запит іде прямо з
  браузера, без ключів. Помилки підкреслюються в тексті, пояснення — польською. Ліміт — 20 перевірок
  на хвилину з однієї IP-адреси.
- **Оцінка твору — Cloudflare Workers AI** (модель Gemma 4, `worker/`): невеликий Worker приймає текст
  і параметри завдання, сам формує запит до моделі й повертає оцінку 1–6, виправлення з поясненнями
  українською, покращену версію й поради. Довільних запитів до моделі Worker не приймає, відповідає
  лише сайтам курсу (GitHub Pages і Netlify) і пропускає до 6 перевірок на хвилину з однієї IP-адреси.
  Безкоштовна квота Cloudflare — 10 000 Neurons на добу (приблизно 400–500 перевірок на всіх
  користувачів); на плані Free після вичерпання квоти запити просто відхиляються до наступної доби, без оплати.

Тексти учнів надсилаються на сервери LanguageTool і Cloudflare лише в момент перевірки.

Деплой Worker (потрібен безкоштовний акаунт Cloudflare):

```bash
cd worker
npx wrangler login
npx wrangler deploy
```

Адреса Worker задається константою `REVIEW_API` у `src/app.js`; порожній рядок вимикає AI-оцінку.

У версії на claude.ai цих кнопок немає: там твори перевіряє Claude, а запити до сторонніх сервісів платформа блокує.

Оновлення Netlify (потрібен вхід у Netlify; CLI збирає курс за `netlify.toml`):

```bash
npx netlify-cli deploy --build --prod
```

## Структура

```
course/SCHEMA.md      формат уроків і повний план курсу
course/m01.js…m12.js  модулі (по 5 уроків)
course/m13.js…m15.js  додаткові модулі (extra: true)
course/exam-a2.js     контрольний тест A2
course/exam.js        підсумковий іспит B1
course/life.js        завдання з життя (по одному на модуль)
course/dialogs.js     сценарії рольових діалогів (по одному на модуль)
src/                  рушій: shell.html, app.css, app.js
tools/validate.js     перевірка контенту: node tools/validate.js
tools/build.js        збирання в один HTML: node tools/build.js → dist/
worker/               Cloudflare Worker для AI-перевірки творів
```
